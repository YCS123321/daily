📖 这是什么

OpenCodeReview 是一个由阿里巴巴开发的高效、可靠的代码审查工具。它采用了混合架构，结合了确定性管道和 LLM 代理，能够提供精确的行级注释。内置了多种语言的规则集，包括空指针异常（NPE）、线程安全、跨站脚本（XSS）和 SQL 注入等，支持 OpenAI 和 Anthropic。这个工具可以帮助开发者在代码提交前进行全面的代码审查，确保代码质量，减少潜在的安全风险。典型的使用场景包括在软件开发过程中，对代码进行审查，确保代码符合安全规范和最佳实践。对于审计师来说，它可以用来审查代码的安全性，确保系统在财务和审计过程中的可靠性。对于备考公务员的朋友，它可以作为一个学习工具，帮助他们理解代码审查的重要性，以及如何在工作中应用这些知识。

🏗️ 怎么设计的

OpenCodeReview 使用 Go 语言编写，其核心架构包括确定性管道和 LLM 代理。确定性管道确保代码审查过程的稳定性和可预测性，而 LLM 代理则能够提供智能化的代码分析。技术栈方面，它集成了 OpenAI 和 Anthropic 的技术，使得代码审查更加智能化。亮点设计包括内置的多语言规则集，能够自动识别和修复常见的编程错误。此外，它的兼容性设计使得它能够轻松集成到现有的开发环境中。

📖 这是什么

Atlas是一个专为编码代理设计的源代码管理工具。它允许用户使用多个编码代理，跟踪他们的更改，并在一个地方查询这些更改。对于审计师来说，这就像是一个集中式的审计日志，可以监控和审查多个代理的财务数据处理过程。例如，审计师可以使用Atlas来跟踪财务软件中不同用户的操作记录，确保数据的准确性和完整性。在公务员备考中，Atlas可以作为一个团队协作工具，帮助团队成员共同编写和审查政策文件或报告，确保文件的一致性和准确性。典型使用场景包括：审计师使用Atlas来监控财务系统的操作，公务员使用Atlas来协作完成政策文件编写。

🏗️ 怎么设计的

Atlas使用Rust语言编写，其技术栈包括Git作为后端存储和Rust的同步框架。核心架构是一个分布式系统，其中每个编码代理都是一个节点，它们通过Git进行版本控制。Atlas的亮点设计在于其高效的并发处理能力和对Git的深度集成。它通过Git的commit历史来跟踪每个代理的更改，并提供了强大的查询接口，允许用户快速定位到特定的更改记录。此外，Atlas还支持跨代理的协作，使得多个代理可以同时工作在同一项目上，而不会相互干扰。
