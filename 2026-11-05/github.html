这是什么

Auto Ontology 是一个基于 Python 的框架，用于在数据上构建语义、基于图的推理层。它能够实现确定性查询生成、更好的上下文检索，以及为大型语言模型和代理工作流程提供更可解释的人工智能。这个项目旨在解决数据分析和查询中的可靠性问题，通过构建一个上下文层，帮助代理了解数据的位置、含义、使用方式、来源以及相似性。对于审计师来说，它可以用来发现和验证企业元数据，确保数据的一致性和准确性，这对于审计过程中的数据分析和报告至关重要。典型使用场景包括：审计师在审查财务报告时，可以使用 Auto Ontology 来发现和验证数据源，确保数据的真实性和可靠性；在考公备考过程中，考生可以使用它来构建知识图谱，提高学习效率和知识检索速度。

Auto Ontology 使用 Python 编写，其技术栈包括但不限于 Python 的标准库、图数据库和自然语言处理工具。核心架构包括元数据发现、语义模型构建、查询生成和验证等模块。其亮点设计包括：1. 元数据发现模块能够从企业数据中自动提取元数据，构建企业本体；2. 语义模型构建模块能够将元数据转换为语义模型，实现数据的语义理解；3. 查询生成和验证模块能够生成确定性查询，并验证查询结果，确保数据的准确性。这些设计使得 Auto Ontology 能够高效地处理大量数据，并提供可靠的查询结果。

gstack是一个将Claude Code（以及其他编码代理）转变为虚拟工程团队的项目。它提供了一系列工具，帮助创始人、CEO、设计师、工程师经理、发布经理、文档工程师和QA人员等角色高效工作。这个项目旨在解决在软件开发过程中，不同角色之间沟通协作的难题，提高团队的生产力和效率。典型使用场景包括：产品重构、架构锁定、设计审查、代码审查、质量保证、安全审计和发布管理等。对于审计师来说，它可以作为一个辅助工具，帮助他们在软件开发过程中进行风险评估和控制，确保软件符合相关法规和标准。对于备考公务员的朋友来说，它可以作为一个学习工具，帮助他们了解软件开发的基本流程和工具，提高他们的技术素养。

怎么设计的

gstack使用TypeScript编写，其核心架构包括以下几个部分：1. 工具集合：提供CEO、设计师、工程师经理、发布经理、文档工程师和QA人员等角色的工具；2. Markdown编辑器：支持Markdown语法，方便用户编写文档和代码；3. 命令行界面：提供简洁的命令行操作方式，方便用户快速执行任务；4. 自动化流程：支持自动化代码审查、质量保证和发布等流程。gstack的亮点设计在于其模块化架构，每个工具都可以独立使用，也可以与其他工具结合使用，满足不同角色的需求。此外，gstack还提供了丰富的文档和示例代码，方便用户学习和使用。
